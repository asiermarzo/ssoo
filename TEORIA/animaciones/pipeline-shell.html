Pipeline de shell: cmd1 | cmd2 | cmd3

Tema 7 · El shell crea una tubería por cada |, hace fork() de cada comando y usa dup2() para redirigir la salida estándar de uno a la entrada estándar del siguiente. Los datos fluyen por el búfer del núcleo de cada tubería.

—
Añadir etapa:
Pulsa «Reproducir» para ver cómo se monta y se ejecuta la pipeline.

Cada comando es un proceso independiente con su tabla de descriptores. Tras dup2(), el descriptor 1 del comando N apunta al extremo de escritura de una tubería y el descriptor 0 del comando N+1 al de lectura de esa misma tubería; el 2 (errores) sigue apuntando al terminal.
